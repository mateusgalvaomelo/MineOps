The synthetic dataset is generated transactionally at backend startup, not checked in as private or real operational data. Download a ZIP containing CSV tables, a multi-sheet XLSX workbook and the schema dictionary from any resource page, `/api/export`, or run `scripts/export-demo.ps1` after Docker starts. Local exports are ignored by Git.

Seed: 2026. Operation: fictional Aurora Mining. Relative history: seven days before startup. No real mine, vendor records, subscriber identifiers or antenna locations are imported.
